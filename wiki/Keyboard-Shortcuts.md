# Keyboard Shortcuts

On macOS, use `Cmd` wherever `Ctrl` is shown.

| Shortcut | Where | Action |
| --- | --- | --- |
| `Ctrl+N` | Anywhere | New meeting, or go back to the recording in progress |
| `P` | Recording screen | Pause / resume the recording |
| `Space` | Meeting page | Play / pause the recording |
| `←` / `→` | Meeting page | Skip back / forward 15 seconds |
| `Ctrl+F` | Meeting page | Search the transcript |
| `Enter` / `Esc` | When renaming | Save / cancel |

Single-key shortcuts don't fire while you're typing in a text field.
